# Методичка NL2

Сайт: **https://naumzool5-sudo.github.io/poker-tools/**

Открывается с любого устройства, на телефон ставится как приложение (Chrome → меню → «Установить приложение»).

## Разделы

| Путь | Что внутри |
|---|---|
| `guide/` | единый вход: вкладки по всем разделам |
| `analyzer/` | анализатор GG-логов: руки, net, рейк, честный рейк, до рейка, позиции, ставки, мин-рейзы, лимпы |
| `checklist/` | чек-лист сессии (v4.2, GG, 2 стола) |
| `postflop/` | постфлоп-план по сценариям |
| `shpora/` | шпора: pot odds, эквити, ауты |
| `combos/` | комбинаторика, лист A4 |
| `math/` | гайд «Эквити и подсчёт комбинаций» |
| `opponents/` | типы оппонентов |
| `charts/` | префлоп-чарты (6-max) |
| `trainer/` | тренажёр чартов (PWA, синхронизация через JSONBin) |
| `hub/` | хаб: план, ментал, ачивки, прогресс, журнал сессий |

## Важно

- **Ключей в репозитории нет.** Синхронизация хаба и тренажёра работает через JSONBin: Bin ID и X-Master-Key вводятся в браузере и хранятся только там.
- **Данные в браузере.** Галочки чек-листа, статистика тренажёра, журнал сессий живут в localStorage устройства и в JSONBin. Обновление файлов на сайте их не стирает.
- **Обновление сайта** — замена файлов в репозитории; страница подхватит новую версию после обновления.
- Архив для офлайн-использования — `tools.zip` в облаке Koofr (в репозиторий не входит).
