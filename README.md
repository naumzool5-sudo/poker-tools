# Методичка NL2 — как открывать

1. Распакуй этот архив целиком в любую папку, например `D:\poker-tools`.
   Важно: распаковывать **всю структуру**, а не отдельные файлы.
2. Открой `guide/index.html` — это единый вход. Разделы переключаются вкладками сверху.
3. Кнопки справа вверху ведут в тренажёр и хаб (они лежат в соседних папках).

## Что где

| Папка | Что внутри |
|---|---|
| `guide/` | единый вход: вкладки по всем разделам |
| `analyzer/` | анализатор GG-логов: руки, net, рейк, до рейка, позиции, ставки, мин-рейзы, лимпы |
| `checklist/` | чек-лист сессии (v4.2, GG, 2 стола) |
| `postflop/` | постфлоп-план по сценариям |
| `shpora/` | шпора: pot odds, эквити, ауты |
| `combos/` | комбинаторика, лист A4 |
| `math/` | гайд «Эквити и подсчёт комбинаций» |
| `opponents/` | типы оппонентов |
| `charts/` | префлоп-чарты (6-max) |
| `trainer/` | тренажёр чартов (PWA, синхронизация через JSONBin) |
| `hub/` | хаб: план, ментал, ачивки, прогресс |

## Если что-то не открывается

- Вкладки «Методички» пустые → файлы распакованы по одной папке, а не целой структурой. Распакуй архив заново целиком.
- Тренажёр просит ключи → Настройки → Синхронизация → Bin ID и X-Master-Key.
- Хаб показывает старые ссылки на Netlify → открыт старый файл; нужен `hub/index.html` из этого архива.

## Обновления

Новая версия архива заменяет файлы целиком. Свои данные (галочки чек-листа, статистика тренажёра, правила хаба) живут в браузере и в JSONBin — замена файлов их не стирает.
